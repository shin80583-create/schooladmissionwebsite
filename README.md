# CampusFlow — School Admission Platform

CampusFlow is a polished, responsive front-end prototype for a modern school admissions and student operations platform.

## Features
- Responsive admissions dashboard
- Application queue with status filters
- Applicant creation modal
- Search applicants
- Application analytics visualization
- Dark mode
- Accessible semantic HTML
- Zero external dependencies

## Run locally
Open `index.html` in a browser. No build step is required.

## Roadmap
The UI is designed to be extended with authentication, a real database, document uploads, notifications, role-based access, and REST/GraphQL APIs.
